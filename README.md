# The invisible flood: Tonle Sap seen by NISAR

*NASA Space Apps 2026: Dancing with SARs. Team **CODEV - Alpha** (United Arab Emirates): Abdul Bari Mohammed Abdul Kaleem (team owner), Abdurahman Khan, Sajid Ali, Bashaer Abdulla Aljneibi.*

Every rainy season Cambodia's Tonle Sap lake swells into the forest around it. Much of that flood is hidden under the trees and under monsoon clouds. NISAR's L-band radar sees through both. This project turns 11 NISAR images (June–October 2026) into an interactive story map for the public and decision-makers.

**What we found** (40 × 40 km area on the north-west shore):
- **Open water** grew from about **610 km² (Jun 19) to 1,050 km² (mid-October)**.
- **Flooded forest** (water under the trees, which makes the radar return very bright) grew about 8× and peaked at about **310 km² on Aug 30**. After that the water rose over the low trees and shrubs.
- **Hypothesis:** the hidden flood under the trees peaks about 5–7 weeks before the open-water flood.
- **Compared with other satellites:** in late August, Sentinel-2 (optical) was half covered by cloud, and Sentinel-1 (C-band radar) showed the flooded forest only faintly. NISAR showed it about 3× more strongly.

- **Story map:** [`site/`](site/), published with GitHub Pages.
- **Methods, step by step:** [docs/PROCESS.md](docs/PROCESS.md).

## Run the pipeline

```
pip install -r requirements.txt
python src/tonlesap.py inventory     # which NISAR images cover the area
python src/tonlesap.py wc_preview    # land-cover map used to place the 40 x 40 km window
python src/tonlesap.py fetchloop     # stream only the window from each ~3 GB file, ~1 min per date
python src/tonlesap.py analyze       # 3-date first look; land cover + Sentinel-2 on the radar grid
python src/tonlesap.py series        # all dates -> outputs/tables/series.csv + areas_over_time.png
python src/tonlesap.py compare       # Sentinel-2 / Sentinel-1 / NISAR, late August
python src/tonlesap.py export        # outputs/web/: one PNG per date, worldcover100.png, dates.json, bounds.json
python src/tonlesap.py webcolor      # colour layers: flood map + NISAR radar colour per date, time-colour, duration
python src/tonlesap.py site          # copy outputs/web + comparison figure into site/
python src/tonlesap.py older         # check for NISAR data before June 2026 (none found)
```

You need a free [NASA Earthdata](https://urs.earthdata.nasa.gov) account. The first login saves it to `~/.netrc` (`_netrc` on Windows). Sentinel and WorldCover data need no account.

## View the site locally

The page loads its data files with `fetch`, so serve the folder rather than opening `index.html` directly:

```
python -m http.server 8000 -d site
```

Then open http://localhost:8000. To jump to a chapter, add `#ch1` … `#ch9` or `#explore` to the address.

The site is plain HTML/CSS/JS. It uses MapLibre GL JS 4.7.1 and Chart.js 4.4.4 from public CDNs, with no API keys.

**Map layers** (all at 100 m, from NISAR HH/HV):

| Layer | What the colours mean |
|---|---|
| Flood map | One meaning per colour: blue = open water (HH < −15 dB), bright green = flooded forest (tree cells with HH ≥ −5 dB), dark green = forest with no flood seen, tan = fields/grass/wetland, grey = town |
| NISAR radar colour | Red = HH, green = HV, blue = HH÷HV, with the same stretch on every date |
| Radar time-colour | Red = 30 Aug, green = 19 Jun, blue = 17 Oct (HH). Pink = forest that lit up in Aug–Oct (the hidden flood) |
| Time under water | In how many of the 10 images (one every 12 days) each cell was open water or flooded forest |
- **Click-to-inspect** reads values back from the same PNGs the map shows, using an exact 8-bit encoding: dB = −22 + value / 255 × 24 (±0.05 dB).
- **Land-cover class** comes from `worldcover100.png`.
